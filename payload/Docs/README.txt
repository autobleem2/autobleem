AutoBleem 2 - user manual

The manuals that used to ship here (WiFi setup, kernel install, Bluetooth pairing, the RetroBoot 1.1
readme, the gamepad list) described AutoBleem 1.x's install on the stock kernel and are gone - none of
it applies to this release.

The current English user manual is bundled next to this file as autobleem-user-manual-en.pdf. Every
language, kept up to date with each release, and the always-current version are on the download site:

    https://autobleem.retromenele.pl/manuals/

(English directly: https://autobleem.retromenele.pl/manuals/autobleem-user-manual-en.pdf)
